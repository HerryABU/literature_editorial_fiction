# 《人间梦：百年家国》全书150回总纲（最终定稿·含具体年份）


## 全书题诗

> 七十年间家与国，半生风雨半生尘。
> 一朝散作星河去，各向茫茫梦里身。


## 上卷·筑城（第1-55回）

**年代跨度：1949—1991年**

**卷首题诗**：
铁壁铜墙初筑就，千门万户一时新。
谁知四十年来事，渐把同心作异心。

**卷末题诗（第55回）** ：
三十年间如转毂，万家灯火几回同。
忽闻北地山河改，始觉人间万事空。


| 回序 | 回目 | 具体年份 | 核心事件与人物命运梗概 |
|:---:|:---|:---:|:---|
| **第1回** | **赤帜初升千户仰，万工归位一炉温** | 1949年10月1日 | 开国大典，工人周铁山（1925年生）作为劳模代表站在天安门观礼台上，认定“新中国就是咱的家”。 |
| **第2回** | **分田令下祠堂圮，老井苔深旧谱焚** | 1950-1952年 | 土改运动，周铁山父亲周老栓分到三亩地，宗族祠堂被拆，族长周老太爷投井。 |
| **第3回** | **鸭绿江寒铁马渡，上甘岭月血衣还** | 1950年10月-1953年7月 | 抗美援朝战争，周铁山表弟方志远报名参加志愿军，在上甘岭战役中负伤。 |
| **第4回** | **夜校灯昏霜满纸，村姑初识姓和名** | 1950-1956年 | 全国扫盲运动，周铁山妹妹周桂花学会写自己名字，成为村妇联主任。 |
| **第5回** | **铁西烟起千炉赤，关外人来万灶青** | 1953-1957年 | 第一个五年计划，周铁山调到沈阳重型机械厂，成为八级钳工，娶了护士李素芬。 |
| **第6回** | **炉吞锅釜三更赤，火噬柴扉十里红** | 1958年秋 | “大跃进”全民大炼钢铁，周老栓藏了一口铁锅，被民兵查出后游街。 |
| **第7回** | **食堂开饭千口共，半锅稀粥百人同** | 1958-1959年 | 人民公社化，公共食堂开张，周桂花带着孩子去食堂吃饭，半年后食堂开始缺粮。 |
| **第8回** | **榆皮剥尽三年馑，草根刨空万户哀** | 1959-1961年 | 三年困难时期，周铁山每月领定量粮票寄回老家，周老栓来信说“村里饿死人了”。 |
| **第9回** | **饥年殁去犹睁目，嘱子休忘故土根** | 1961年冬 | 周老栓饿死，临终遗言：“告诉铁山，别忘了咱是周家的人。” |
| **第10回** | **大庆烟高冲斗柄，大寨崖裂辟田畴** | 1964-1965年 | 工业学大庆、农业学大寨运动全面展开，周铁山被评为“学大庆标兵”，赵大柱在大寨被山石砸伤腿。 |
| **第11回** | **戈壁云腾惊帝座，万家烛火照天明** | 1964年10月16日 | 中国第一颗原子弹爆炸成功，周铁山在厂里听广播和工友们欢呼，表弟方志远正是该项目技术人员之一。 |
| **第12回** | **一桩小事传天下，半尺螺钉见本真** | 1963年3月 | 毛泽东题词“向雷锋同志学习”，周铁山在车间号召工友学雷锋，徒弟孙满囤积极响应。 |
| **第13回** | **东方一曲星升瀚，塞北千家夜听春** | 1970年4月24日 | 中国第一颗人造卫星“东方红一号”发射成功，周铁山在厂里听收音机传回的《东方红》乐曲，工友们相拥而泣。 |
| **第14回** | **蜀道千盘迁铁马，峡深百里起烟囱** | 1965-1970年 | 三线建设大规模展开，方志远从新疆调往四川某三线工厂，从此与周铁山彻底失去联系。 |
| **第15回** | **氢云再裂乾坤动，一爆重开日月新** | 1967年6月17日 | 中国第一颗氢弹爆炸成功，周铁山看到号外，孙满囤敲门来道贺——周铁山没开门。 |
| **第16回** | **一桥飞架千帆过，天堑从今不隔江** | 1968年9月 | 南京长江大桥建成通车，周铁山在厂里看纪录片，感慨：“中国人自己造的桥，比苏联人修的气派。” |
| **第17回** | **十年汗雨浇新础，百业蒸云接故城** | 1965年 | “调整、巩固、充实、提高”方针实施，国民经济恢复，周铁山一家从工厂宿舍搬进工人新村两居室。 |
| **第18回** | **炉火十年终淬刃，楼台百丈始擎天** | 1965-1966年 | 工业体系初步建成，周铁山带出第一批徒弟，其中就有孙满囤。 |
| **第19回** | **大字满墙雷破夜，故人翻眼客成仇** | 1966年5月 | “文化大革命”开始，沈阳重型机械厂成立“革命造反团”，周铁山因“技术权威”被贴大字报，徒弟孙满囤带头批斗他。 |
| **第20回** | **铁牌挂颈寒如剑，素手遮儿泪作纱** | 1967年春 | 周铁山被挂牌游街，罪名是“反动技术权威”，李素芬每天给周铁山送饭，被造反派拦阻仍坚持。 |
| **第21回** | **权移稚子登高座，义断师徒各闭门** | 1968年 | 孙满囤成为厂革委会副主任，周铁山下放铸造车间搬铁砂，师徒彻底决裂。 |
| **第22回** | **城楼挥手千山远，屯垦风沙万里沉** | 1968-1969年 | 知识青年上山下乡运动全面展开，周建国（1958年生）被分配到黑龙江生产建设兵团。 |
| **第23回** | **荒原一镐开新土，家信三秋抵万金** | 1969-1972年 | 周建国在北大荒开荒种地，三年只回过一次家，他在信中写道：“爸，这里的土地比咱老家还大，可我总梦见咱家的炕。” |
| **第24回** | **寒江枪碎三更月，铁甲霜凝两国仇** | 1969年3月 | 珍宝岛中苏边境冲突爆发，周建国的兵团被动员备战，他写了遗书寄回家。 |
| **第25回** | **折戟草原星坠北，焚书殿阁月沉西** | 1971年9月13日 | 林彪坠机事件，孙满囤在厂里组织批判会，周铁山在台下沉默不语。 |
| **第26回** | **一穗新苗天赐绿，万村饥灶待炊烟** | 1973年 | 袁隆平籼型杂交水稻研究成功，周桂花在村里试种杂交水稻，亩产翻倍。 |
| **第27回** | **十年冻土埋春色，一纸归文换鬓霜** | 1972-1978年 | 知青返城政策迟迟未出，周建国与兵团女知青刘小燕恋爱，约定“一起回城”。 |
| **第28回** | **四孽烟消天破晓，十秋雨落夜收声** | 1976年10月6日 | 粉碎“四人帮”，周铁山在厂里听到消息，对李素芬说：“终于到头了。” |
| **第29回** | **九日霜寒天地恸，万山云黯鼓钟沉** | 1976年9月9日 | 毛泽东逝世，周铁山在厂里参加追悼会，哭得站不住。 |
| **第30回** | **地裂一宵城尽碎，魂飞廿万泪成河** | 1976年7月28日 | 唐山大地震，24.2万人遇难，周铁山组织厂里捐款，李素芬主动报名赴唐山医疗救援。 |
| **第31回** | **一策重开千卷路，万生齐叩省城扉** | 1977年秋 | 高考制度恢复，570万人走进考场，周建红（1963年生）立志考大学，周建国在兵团彻夜未眠。 |
| **第32回** | **春雷破冻京西夜，门户初开四海风** | 1978年12月18-22日 | 十一届三中全会召开，周铁山在厂里听传达，对李素芬说：“变了，真的变了。” |
| **第33回** | **红榜一名惊陋巷，青灯十载换门楣** | 1978年夏 | 周建红考入辽宁师范大学，周铁山摆了三桌酒请工友，孙满囤没来。 |
| **第34回** | **十年汗浸荒原土，一纸官文返故城** | 1979年春 | 知青返城政策落实，周建国回到沈阳，与恋人刘小燕分手，给周铁山的信只写了七个字：“爸，我回来了。” |
| **第35回** | **一店初开街巷窄，万金首上榜文新** | 1979-1983年 | 改革开放后个体经济兴起，周建国辞去街道小厂工作，借钱开五金店，第一年赚八千元。 |
| **第36回** | **杏坛三尺桃千树，教案半生鬓百丝** | 1982年秋 | 周建红大学毕业，被分配到县城中学教语文，她在课堂上讲《谁是最可爱的人》，讲到志愿军时哭了。 |
| **第37回** | **荧屏方寸千家聚，西游万里万人空** | 1986年 | 电视机普及，1986版《西游记》播出，周铁山花四百元买十四寸黑白电视，整条胡同的人都来他家看。 |
| **第38回** | **业大难容同灶火，分飞各自筑新巢** | 1986年 | 周建国在沈阳买商品房搬出工厂宿舍，周铁山对李素芬说：“一家人住在一起的日子，怕是到头了。” |
| **第39回** | **病榻乡间空望眼，兄归已是纸灰寒** | 1986年冬 | 周桂花因肺心病去世，终年53岁，周铁山赶回老家时妹妹已下葬，在坟前跪了一夜。 |
| **第40回** | **一夜价飞千物贵，满城争抢万民狂** | 1988年夏 | 价格改革“闯关”引发物价飞涨和抢购风潮，周建国囤了十箱肥皂被周铁山骂“奸商”。 |
| **第41回** | **一纸新章开首户，半生旧债换招牌** | 1988年 | 《私营企业暂行条例》颁布，周建国注册“建国五金建材公司”，成为沈阳第一批私营企业主。 |
| **第42回** | **三十年华如烛转，万家灯火各西东** | 1989年除夕 | 周家三代人吃年夜饭——周铁山夫妇、周建国一家、周建红一家，周铁山看着满桌菜说：“你姑姑要是还在，就好了。” |
| **第43回** | **铁厂沉沉闻拆灶，工牌默默换行囊** | 1990年 | 国企改革深化，部分工厂开始裁员，周铁山的老工友人心惶惶，孙满囤宣布“减员增效”。 |
| **第44回** | **童手翻书星斗乱，残编入梦甲衣寒** | 1990年 | 海南摄影美术出版社盗版《圣斗士星矢》进入中国，周明远（1980年生）第一次看到日本漫画，被父亲撕毁后哭了三天。 |
| **第45回** | **歌楼彻夜霓虹乱，百姓初闻午夜声** | 1990-1991年 | KTV、舞厅等娱乐场所大量出现，周建红在县城看到年轻人唱卡拉OK，对学生说：“你们赶上好时候了。” |
| **第46回** | **病榻萧萧来客少，空廊寂寂旧人稀** | 1991年春 | 周铁山因肺气肿住院，来看望的老工友不到五人，孙满囤托人送来水果，周铁山说“扔了”。 |
| **第47回** | **红场雪落红旗降，老翁屏前坐到明** | 1991年12月25日 | 苏联正式解体，周铁山盯着电视看了两个小时，对李素芬说：“老大哥没了。” |
| **第48回** | **一纸合同成死锁，半生心血付空流** | 1991年冬 | 经济滑坡，周建国的公司被三角债拖垮，他在办公室坐了一夜。 |
| **第49回** | **租架初开童稚满，旧书翻烂指痕深** | 1991年 | 沈怀仁在县城开了第一家漫画租书店，周明远第一次走进去，看到满架盗版漫画。 |
| **第50回** | **山河未改人先老，灯影依然客已非** | 1991年除夕 | 周家年夜饭只有周铁山夫妇、周建国、周明远四人，周铁山举杯，手在抖：“这个家，越来越小了。” |
| **第51回** | **两角钱租千卷烂，一灯影照百书开** | 1991-1992年 | 沈怀仁的租书店生意火爆，月入三千，超过县城工人三倍工资。 |
| **第52回** | **南岛盗印圣斗士，两元一册价如珍** | 1991-1992年 | 海南摄影美术出版社盗版《圣斗士星矢》，沈怀仁从海口进书，周明远排队三小时买到第一册。 |
| **第53回** | **一册拆成双册卖，少年攒得一年愁** | 1992-1993年 | 海南社将《龙珠》42册拆成78册，周明远攒了三个月零花钱买齐，书包里永远藏着一本。 |
| **第54回** | **半月一刊天下动，龙珠同步万人观** | 1993年8月 | 《画书大王》创刊号面世，首期销量80万册，主编钱国梁一夜成名，沈怀仁投稿被刊出。 |
| **第55回** | **廿四期成秋叶落，一朝梦断画王寒** | 1994年8月 | 《画王》出至第24期被停刊，钱国梁南下广州，沈怀仁的租书店开始走下坡路。 |


## 中卷·裂谷（第56-111回）

**年代跨度：1992—2023年**

**卷首题诗**：
金樽不夜笙歌起，玉树临风冠盖连。
谁料繁华深处里，蚁穴已蛀万重山。

**卷末题诗（第111回）** ：
满城灯火人如织，谁见万家灯下孤。
三十年间如梦过，满园花落尽成无。
