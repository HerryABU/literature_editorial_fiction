

# 公开课

公开课开始前五分钟，评委入座。

教室后排摆了七张折叠椅，椅背上贴着手写姓名的纸条。教研组长坐在中间，左手边是分管教学的副校长，右手边是区教研员。他们的评分表已经翻开，第一栏写着“教学目标设计”，第二栏“教学过程实施”，第三栏“学生参与度”，第四栏“创新手段运用”。每栏后面都是空格，等着被打上分数。

讲台上放着一个木盒。盒盖打开着，里面码着一叠卡片。卡片尺寸比扑克牌大一圈，每一张都是手绘的。最上面那张画着一只雪豹，尾巴横贯画面，几乎和身体一样长。右下角用细笔写着一个字母。

上课铃响了。生物老师站在讲台上，灰色衬衫，袖口卷到小臂。他没有用PPT，没有放视频，只是把木盒往讲台中间推了推。

“今天这节课，”他说，“我们用一种特殊的方式学习动物的行为特征。”

他拿起最上面那张卡片，翻过来给全班看。

“触碰这张卡片，”老师说，“你就可以获得这个动物的视角。”

后排的教研组长点了点头，在“创新手段运用”一栏打了个草稿。

“谁想第一个试试？”

一个坐在第三排的男生举了手。老师走过去，把卡片递给他。男生接过卡片，低头看了看画面上的雪豹，然后伸出食指，碰了碰卡面的边缘。

变化发生得很快。先是他的轮廓模糊了，像是有人在他身上泼了一层半透明的颜料；然后是尾巴——从尾椎骨的位置生长出来，灰白色的皮毛上嵌着黑色环斑，几乎和身体一样长。他低头看见自己的手变成了灰白色的毛爪，指节粗短，爪尖微弯。他猛地扭头去看身后——尾巴搭在椅背上，尾尖垂下来，晃了一下。

“我靠……”他小声说。

他伸手想去摸自己的尾巴，手指碰到毛皮的瞬间缩了回来，像是被烫了一下。然后他又伸手，这次抓住了尾尖，拉过来看了看——灰白色的皮毛，黑色的环斑，真实的触感。“这是真的。”他说。

后排响起低低的笑声。他这才意识到全班都在看他。他松开尾巴，尾巴垂回椅背边缘，晃了一下，又晃了一下。他不知道怎么让它停下。他缩了缩肩膀，耳朵——他不知道自己什么时候长了耳朵，但头顶确实有东西在动——往后撇了一下。

同桌伸手想去碰他的尾巴。他下意识地往旁边躲了一下，尾巴从椅背边缘滑落，拖到地上。同桌的手停在半空中，愣了一下，收回去了。

“他好像有点紧张，”老师说，“雪豹本来就是回避性很强的动物。这位同学现在体验到的，就是雪豹在陌生环境里的本能反应。”

老师转身在黑板上写了两个字：回避。

“大家注意观察，他现在的耳朵是向后撇的，这是猫科动物紧张时的典型体态。”

男生坐在那里，尾巴拖在地上，灰白色的皮毛上浮着黑色环斑，耳朵向后撇着。他不知道自己的尾巴拖了多长——他只是觉得那条尾巴很重，像有什么东西从身后坠着他，让他坐在椅子上不知道该怎么放自己的身体。他想让它收起来，但尾巴不听话。它只是拖在那里，尾尖偶尔动一下。

“老师，”他开口，声音有点发闷，“我能变回来吗？”

“再碰一下卡片就行。”

他低头去够卡片——卡片躺在课桌上，他伸出灰白色的毛爪，爪尖碰到了卡面边缘，推了一下，没拿起来。又推了一下，卡面转了半个圈。后排又有笑声。他的尾巴从地上弹起来，毛炸开了一圈。

他终于把卡片捏起来了。指尖碰到卡面的瞬间，尾巴、皮毛、斑点、耳朵——所有变化像水渍被风吹干一样消失了。他坐在那里，浅棕色的手放在桌面上，呼吸有点急促，额头沁出一层薄汗。同桌又伸手拍了拍他的肩膀，他这次没有躲。

“感觉怎么样？”老师问。

“……尾巴太长了，”他说，“一直拖在地上。”

后排的教研组长在“学生参与度”一栏打了个勾。老师的手机震了一下，他低头看了一眼——是教研组长发来的消息：“注意节奏，不要超过15分钟。”

“还有谁想试试？”

没有人举手。前排的女生低下了头，后排的男生把目光移向窗外。教室里安静了几秒。

“那好，”老师说，“我们继续往下走。”

他没有再拿出第二张卡片。他打开PPT，开始讲雪豹的分布区域和食性特征。知识点一个接一个出现在屏幕上，语速平稳，偶尔停顿一下，确认没有人提问。后排的教研组长低头在评分表上写了几个字，又抬头看屏幕。

那个男生坐在第三排，笔记本翻在那一页上，笔握在手里，一个字没写。他盯着自己的手——浅棕色的皮肤，指节分明，刚才那些灰白色的皮毛已经不见了。但他还能感觉到那条尾巴的重量，拖在身后的那种坠感，像有什么东西还没完全离开。

四十五分钟的课很快过去了。PPT翻到最后一页的时候，下课铃刚好响了。老师合上电脑，拍了拍手。

“今天的课就到这里，”他说，“大家可以写一篇观察笔记，记录今天的学习内容。”

学生们收拾书包往外走。那个男生把笔记本合上放进书包里。那一页上只有一行字——“尾巴太长，一直拖在地上”——写完之后就再也没有打开过。

评委从后排站起来，互相交换了几句客气话。“环节设计流畅。”“学生参与度高。”“技术手段新颖。”“值得推广。”

他们经过讲台，没有人低头看一眼那个木盒。

评课室里，教研组长把评分表汇总到一起。

“总评：优秀。”

他在教学建议栏里写道：“建议将本课教学模式向全校推广，作为数字化教学转型的典型案例。”

副校长端起茶杯，点了一下头。“这个课可以推出去参加市里的评比。”

“什么主题？”另一位评委问。

“创新教学模式探索——沉浸式体验在生物教学中的应用。”

教研组长在备注栏里加了一行字：“学生反映良好，课后观察笔记待提交。”

他合上评分表。没有人提到那个男生变身后缩着肩膀的样子，没有人提到他伸手去摸尾巴时手指缩回来的那一下，没有人提到那条尾巴拖在地上时他脸上的表情，没有人提到笔记本上那行字——唯一被记录下来的、关于这节课真正发生的事。

那叠卡片依然躺在讲台抽屉里。

第二天，全校教师例会上，教研组长通报了昨天的公开课评分结果。

“92分，”他说，“区级优秀课例。”

然后是程序性的讨论——案例撰写谁来做、视频剪辑谁负责、申报材料什么时候交。没有人提到那些卡片，没有人提到卡片右下角的字母。

那叠卡片依然躺在讲台抽屉里。

没有人再碰过它们。
